# NPTEL Exam Preparation Portal

An interactive, responsive, and 100% offline-ready quiz portal for NPTEL exam preparation.

## Features
- **Two Complete Courses**:
  - **Design Course**: 120 Questions (Weeks 1–12)
  - **Organisational Behaviour Course**: 120 Questions (Weeks 1–12)
- **True Randomization**: Questions are shuffled via Fisher-Yates on every attempt.
- **Instant Answer Feedback**: Highlights correct/incorrect answers with option-level explanations.
- **Interactive 120-Question Palette**: Jump to any question and track status (Answered, Flagged, Unanswered).
- **Bookmark & Flag for Review**: Mark questions to revisit anytime.
- **Detailed Analytics**: Comprehensive results screen with score breakdown and filtered review.
- **Keyboard Shortcuts**: Easy navigation (`1`-`4`, `Enter`, `←`/`→`, `F`).
- **Fully Offline**: 100% self-contained single HTML file.

## GitHub Pages Deployment
This repository is configured to be hosted directly using GitHub Pages:
1. Go to **Settings** > **Pages** in this GitHub repository.
2. Under **Build and deployment** > **Branch**, select `main` (root) and click **Save**.
3. Your quiz will be live at `https://<username>.github.io/<repo-name>/`.
